# Sprint_5
## UI-автотесты для учебного сервиса «Доска»
**В файле tests представлены 4 теста:**

1. Файл ```test_user_registration``` – проверяет регистрацию пользователя по 3-м сценариям  
2. Файл ```test_user_login``` – проверяет возможность логина 
3. Файл ```test_user_logout``` – проверяет возможность логаута
4. Файл ```test_creating_advert``` – проверяет возможность размещения объявления по 2-м сценариям

Установить необходимые зависимости можно с помощью команды: ```pip install -r requirements.txt```
